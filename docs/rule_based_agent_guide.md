# 🤖 Rule-Based Agent (Zero-Token) User Guide

## ১. এটি আসলে কী?
Rule-Based Agent হলো QuestionShaper AI Workspace-এর এমন একটি সিস্টেম যা দেখতে ঠিক AI-এর মতো মনে হলেও, ব্যাকগ্রাউন্ডে এটি কোনো LLM (যেমন- ChatGPT/Gemini) ব্যবহার করে না। এর প্রধান কাজ হলো **0 টোকেন** খরচে ডাটাবেস থেকে রুলস মেনে ডেটা প্রসেস করা (যেমন- এক্সাম পেপার তৈরি করা)।

## ২. টিচাররা কীভাবে এটি ব্যবহার করবেন?
টিচারদের জন্য এটি ব্যবহার করা অত্যন্ত সহজ, কারণ তারা বুঝতেই পারবেন না যে এটি কোনো AI নয়। 
1. **AI Workspace-এ যান:** `/ai-workspace` প্যানেলে প্রবেশ করুন।
2. **`+ Tools` মেনু খুলুন:** চ্যাটবক্সের বাম পাশে থাকা `+` আইকনে ক্লিক করুন।
3. **Auto Exam Generator সিলেক্ট করুন:** মেনু থেকে এই টুলটিতে ক্লিক করলে পেজ রিলোড বা রিডাইরেক্ট হবে না। 
4. **চ্যাটের ভেতরেই ইন্টারঅ্যাকশন:** চ্যাটের ভেতরেই একটি চমৎকার "মিনি-ফর্ম" (Interactive Widget) চলে আসবে। 
5. **ইনপুট দিন:** সেখানে Subject, Exam Title, Total Questions এবং Difficulty সিলেক্ট করে `Build Exam` বাটনে ক্লিক করলে সিস্টেম স্বয়ংক্রিয়ভাবে এক্সাম তৈরি করে Nexus Editor-এ পাঠিয়ে দেবে। 

## ৩. অ্যাডমিনরা কীভাবে এটি কন্ট্রোল করবেন?
সুপার অ্যাডমিন বা ইনস্টিটিউট অ্যাডমিনরা এই সম্পূর্ণ সিস্টেমটিকে **AI Command Center** থেকে নিয়ন্ত্রণ করতে পারবেন। 

### ⚙️ Command Settings (`/ai-workspace/admin/settings`)
এখান থেকে অ্যাডমিনরা সিস্টেমের মূল ব্রেইন কন্ট্রোল করবেন।
* **Global Response Mode:** এখানে একটি টগল সুইচ থাকবে যা দিয়ে অ্যাডমিন ঠিক করবেন সিস্টেম কি `Strict Mode` (Zero-Token Rule-Based) এ চলবে, নাকি `Creative Mode` (LLM Generation) এ চলবে।
* Strict Mode চালু থাকলে সিস্টেম সবসময় আগে ডাটাবেস থেকে প্রশ্ন খুঁজবে।

### 🧠 Prompt & Rules (`/ai-workspace/admin/prompts`)
এখান থেকে রুল-বেসড সিস্টেমের ব্যাকএন্ড রুলস কনফিগার করা যাবে।
* **Schema Definition:** অ্যাডমিনরা এখানে JSON ফরম্যাটে বলে দিতে পারবেন যে কোন সাবজেক্টের জন্য কতগুলো MCQ বা CQ লাগবে।
* উইজেট যখন রিকোয়েস্ট পাঠাবে, তখন ব্যাকএন্ড এই রুলসগুলো চেক করে সেই অনুপাতে প্রশ্ন জেনারেট করবে।

## ৪. এর সবচেয়ে বড় সুবিধা কী?
1. **১০০% খরচ সাশ্রয়ী:** লক্ষ লক্ষ ইউজার ব্যবহার করলেও কোনো API টোকেন খরচ হবে না।
2. **ভুল হওয়ার সম্ভাবনা শূন্য (Zero Hallucination):** যেহেতু এটি এআই দিয়ে নতুন করে বানাচ্ছে না, বরং ডাটাবেসের প্রশ্ন সরাসরি দিচ্ছে, তাই প্রশ্নের মান ও নির্ভুলতা ১০০% নিশ্চিত থাকে।
3. **বিদ্যুৎ গতির পারফরম্যান্স:** LLM-এর জন্য অপেক্ষা না করে সাথে সাথেই কয়েক মিলি-সেকেন্ডের মধ্যে এক্সাম পেপার রেডি হয়ে যায়।
